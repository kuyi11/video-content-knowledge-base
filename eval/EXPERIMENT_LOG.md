# RAG 实验日志

本日志只记录有对照数据的优化。机器可读版本位于
`eval/experiment_registry.json`，可通过
`uv run --no-sync python tools/validate_experiments.py` 校验。

| --- | --- | --- | --- | --- |

## EXP-20260917-profile-dedup

- 假设：同一视频的多个 profile 不应重复占用 Top K。
- 结果：29 文档、352 chunk 快照上，Recall@5 从 `0.7500` 提升到 `0.8571`。
- 结论：保留为默认行为。
- 限制：早期实验只保留聚合指标，不能与当前 33 文档结果直接比较。

## EXP-20260917-query-rewrite

- 假设：追加规范医学术语可以改善同义查询。
- 结果：Recall@5 从 `0.8571` 降至 `0.8214`，MRR 从 `0.6839` 升至
  `0.6964`，平均延迟增加 `9.077 ms`。
- 结论：收益不稳定，默认关闭，只保留显式实验入口。
- 限制：属于 29 文档历史快照，当前语料需要重新评测。

## EXP-20260918-reranker-expanded

- 假设：RRF 先召回 20 个候选，再用本地 CrossEncoder 重排，可改善精确来源命中。
- 控制变量：相同 33 文档、533 chunk、30 条问题和 Top 5 输出。
- 结果：Recall@5 `0.7857 -> 0.8929`，MRR `0.6696 -> 0.7798`，来源覆盖率
  `0.7857 -> 0.8750`。
- 代价：平均总检索延迟 `61.95 ms -> 1226.13 ms`。
- 结论：质量优先或离线场景启用，在线默认仍使用 RRF。

## EXP-20260918-canonical-citation

- 假设：直接提供完整 citation 可减少模型自行拼接引用造成的错误。
- 结果：单次回归中，claim 引用完整率 `0.8571 -> 1.0000`，语义支持率
  `0.8286 -> 1.0000`，复核数 `9 -> 0`。
- 结论：保留引用格式与拒答识别修复，但将结果标记为待复验。
- 限制：这不是严格单变量实验；生成器和裁判均为 `qwen2.5:7b`，且两次运行的
  claim 数不同，因此不能把增量解释为独立正确率提升。

## EXP-20260918-evidence-boundary-dedup

- 假设：按 `###` 子标题切分可让 claim 与其 `source_refs` 留在同一块；重排后按
  `video_id + source_refs` 去重可避免相同证据挤占 Top 5。
- 对照：旧 533-chunk evidence-v1 + reranker；变体：577-chunk evidence-v2 +
  post-rerank evidence dedup。源文档和 30 条问题相同，切块数变化是实验处理的一部分。
- 结果：Recall@5 `0.8929 -> 1.0000`，MRR `0.7798 -> 0.9077`，来源覆盖率
  `0.8750 -> 0.9821`，总检索延迟 `1226.13 ms -> 998.59 ms`。
- 原三个硬例 `medical-003`、`medical-017`、`medical-018` 分别升至第 `1/1/2` 名。
- 结论：保留两项工程修复；reranker 因约 1 秒延迟仍按需启用。
- 限制：这是组合回归，不能拆分单项贡献；`cross-001` 仍只覆盖两个目标来源中的一个。

## 新实验模板

新增实验时必须同时更新注册表和本日志，并满足以下条件：

1. 固定语料文档数、chunk 数、评测集和 Top K。
2. 明确 control 与 variant，只改变一个主要变量；组合改动必须标记为
   `bundled_regression`。
3. 同时记录质量指标和延迟，不只记录正向指标。
4. 保存可提交的聚合 baseline；逐题报告可留在被 Git 忽略的 `eval/reports/`。
5. 记录失败样本、局限、采用决策和实现提交。
6. 生成式评测至少重复运行三次；涉及语义裁判时优先使用独立模型或人工盲审。
